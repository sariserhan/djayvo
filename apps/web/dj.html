    Session notes, controls & sound credits

    Imported tracks stay in this tab unless you enable device-only set recovery. C is saved when you choose Save C on this device or explicitly enable set recovery; nothing is uploaded. Files: up to 100 MB / 20 minutes. Pause a deck to replace it. Use Unload on either deck to remove its track; cleared instruments remain available.

    Enter each track’s BPM or tap it manually. Match tempo adjusts playback rate only; it does not align beats. Course tracks and imports with Enable beat controls use shared-clock playback with continuous pitch, beat loops and four-beat jumps. Enable Key lock to preserve pitch while changing tempo. Align declared grid uses the entered BPM and file start; Pro also lets you set and nudge a manual first beat. This is not automatic beat detection. Other imports use native playback: whole-track repeat may gap and active pitch changes pause briefly. After enabling beat controls, dragging a platter plays its audio forward or backward at the movement speed. Holding still stops the sound; release resumes a previously playing track. Native playback uses jog seeking. Pro has eight hot cues per deck and optional grid quantizing for newly set cues and waveform seeking. Pro pad modes add fractional beat loops, rolls and forward/backward beat jumps. Hold reverse plays backward; with Slip reverse on, releasing returns to the uninterrupted timeline.

    Deck effects shape A and B independently, including prepared A. Tone softens the highs; Echo adds three fading repeats. Reverb adds a short room tail, Phaser sweeps phase notches, and Flanger blends a moving short delay. Pro can link deck echo spacing to the entered BPM and playback speed, within the 100–800 ms range; changing spacing bends the echoes’ pitch. Channel level, crossfader and Master also control echoes. Pausing one deck lets echoes finish. Reset effects, Unload and Pause all clear deck echoes.

    The piano covers A0–C8. Talk bass opens the computer-keyboard register at C2; octave buttons change it. Mouth shape changes its tone, not its pitch. Guitar keys use the cleared bank’s E2–G5 range. Sustain holds released notes; All notes off releases every voice. Leaving the page or keyboard focus stops held instrument notes. Tone softens the high frequencies; Echo adds fading repeats to keys and pads. Echo spacing is manual, not beat-synchronized. Changing spacing bends the echo pitch. Echo tails may continue after All notes off; Reset effects removes echoes, and Instrument level or Master at zero silences them.
