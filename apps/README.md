# Djayvo applications

[Browser Instant Remix](web/README.md) is the current owner-selected priority.
It runs the shared engine locally through WebAssembly, with browser capture,
import/trim, three styles or club, playback, persistence and WAV downloads.
See [web evidence](../docs/web-instant-remix.md). Further phone work is paused.

[Native iPhone/iPad Instant Remix](ios/README.md) wraps the shared portable C++17
core in SwiftUI/AVFoundation. Simulator, device and release evidence are tracked
separately in [the iOS report](../docs/ios-instant-remix.md).

The desktop CLI remains in `tools/cli/`. No desktop GUI or Android app is shipped.
