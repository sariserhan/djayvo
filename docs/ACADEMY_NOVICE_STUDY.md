# DJ Academy novice study protocol

Status: **NOT RUN**. No fabricated participants or certificates. Initial owner
feedback is in `evidence/academy/owner-feedback.json` and is not a cohort result.

Recruit at least five consenting people without DJ experience. Give only the
lesson URL, an ordinary laptop/browser and a comfortable output-volume instruction.
Do not explain the permission/load sequence verbally. Explain that this evaluates
the product, not the person; stopping is allowed. Do not record faces, microphone
or identifiable audio. Use anonymous participant codes and store optional comments
only with permission. Keep any recruitment identities separately.

For each participant record:

| Field | Measurement |
|---|---|
| Participant / environment | Anonymous code, browser/version, keyboard or pointer, speakers/headphones |
| Start / first audible Deck A | Elapsed seconds, success within first minute or actual failure |
| Preparation | Found permission and loaded both tracks unaided? |
| Each task | Attempts, failure messages, hints/demo used, checked or abandoned |
| Free Jam | Did playback continue? Did they understand Continue was voluntary? |
| First transition | Finished unaided, needed handholding, or abandoned; don't convert assistance to unaided PASS |
| Clarity / enjoyment | Separate self-reported 1–5 ratings and optional exact comments |
| Audio | Perceived clipping/crackle, mismatched beats, uncomfortable loudness, browser interruption |
| Keyboard/accessibility | Focus visibility, controls reachable, instructions understandable without color/audio hints |

Retain all attempts and criticism. Report numerator/denominator and missing data;
five successes do not establish professional competence or general population
outcomes. The owner initially failed preparation, so repeat that test after the
onboarding fix before expanding course claims.

The additional three-person beginner mini-set study is **NOT RUN** and currently
blocked by the missing multi-transition mini-set assessment and a larger,
phase/phrase-annotated licensed teaching pack. Do not substitute the 4-second
crossfade or a gain-staging exercise for that requirement.
